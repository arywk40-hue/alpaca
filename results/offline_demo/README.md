# VegaGuard offline demo

This bundle is credential-free and does not contact Alpaca or submit orders.

- `strategy_replay.json` shows deterministic fixture accounting.
- `scorer_comparison.json` compares offline scorers and thresholds.
- `simulated_lifecycle.json` shows the fixture-only scan → candidate → risk → simulated entry → monitoring → simulated exit path.
- `demo_summary.json` summarizes generated artifacts and limitations.

It is not a claim of historical or paper-trading performance. See `docs/ARCHITECTURE.md` and `docs/HISTORICAL_DATA_LIMITATIONS.md` in the repository for the evidence boundary.
